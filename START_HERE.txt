1. .env.example файлын .env деп көшіріңіз.
2. .env файлына OpenAI кілтін жазыңыз:
   OPENAI_API_KEY=sk-...
3. start_site.bat файлын екі рет басыңыз.
4. Браузерде http://127.0.0.1:8000/ ашылады.

Егер компьютерде Python жоқ болса:
- ең ыңғайлы шешім: осы жобаны .exe ретінде жинау;
- немесе сайтты интернетке backend-пен орналастыру.

GitHub Pages тек карточкаларды көрсетеді. ЖИ сұрақтары үшін құпия OpenAI кілті бар backend керек.
